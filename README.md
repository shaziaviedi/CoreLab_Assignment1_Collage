## Sources

**Floor 2 archive conveyor (drag & inertia & seamless loop)**  
Pattern adapted from [Draggable Marquee with Inertia — CodeFronts](https://codefronts.com/motion/css-infinite-marquee/draggable-marquee-inertia/): one `requestAnimationFrame` loop owns position, modulo wrap for seamless looping, pointer velocity sampled on drag, friction decay back into cruise speed.

**Floor 1 PNG-only clicks (alpha hit-test)**  
Clicks ignore transparent padding by drawing each person PNG to an offscreen canvas and reading the alpha byte at the mapped pixel. Approach based on the canvas pixel-read pattern in [Stack Overflow: click through transparent PNG](https://stackoverflow.com/questions/38487569/click-through-png-image-only-if-clicked-coordinate-is-transparent), using [`CanvasRenderingContext2D.getImageData()`](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/getImageData) / [pixel manipulation with canvas](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Pixel_manipulation_with_canvas) (MDN). Pointer coords are converted into natural image space with `object-fit: contain` math before the alpha check.

**Layout coords under elevator `transform: scale(...)`**  
The stage is scaled, so `getBoundingClientRect()` returns _rendered_ sizes while `offsetWidth` / `offsetLeft` stay in _layout_ space. Floor 2’s marquee seam math and Floor 3’s sparkle origins use `offset*` for that reason — see [MDN: Determining the dimensions of elements](https://developer.mozilla.org/en-US/docs/Web/API/CSS_Object_Model/Determining_the_dimensions_of_elements) (transforms change `getBoundingClientRect`, not `offsetWidth` / `offsetHeight`).

**Floor 3 star step-rotate**  
Idle stars jump 20° at a time with `animation-timing-function: steps(18)` on a 0→360° keyframe (not a smooth spin). Documented in [MDN: `steps()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/easing-function/steps) and [CSS-Tricks: `steps()`](https://css-tricks.com/almanac/functions/s/steps/). Hover uses `animation-play-state: paused` plus a rear glow.

**Multi-page elevator ride state**  
Floor trips hand off across `index.html` / `floor1–3.html` with [`sessionStorage`](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage) (pending arrival, from/to floor) so the ride feels continuous in one tab without a single-page router — see also [Using the Web Storage API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Storage_API/Using_the_Web_Storage_API) (MDN).

**Reduced motion**  
Continuous motion (marquees, star steps, woman sway) respects [`prefers-reduced-motion`](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion) (MDN); interactions like star reveals and floor travel still work without the decorative animation.
